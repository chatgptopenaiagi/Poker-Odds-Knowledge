# Publication provenance

The HIL local repository and prior release archives were preserved. A bounded audit scanned all reachable Git blobs/commit metadata and each preserved HIL ZIP. Earlier reports contain local machine paths, a session identifier and environment details. Those files and the original reachable history are not publication inputs.

POK therefore uses a separate sanitized publication repository/history. It contains reviewed source, lockfiles, generic configuration, third-party notices and sanitized verification reports. Local credentials, databases, mailbox contents, user notebooks, private conversation content, screenshots containing tokens and raw workstation evidence are excluded. No existing remote is force-rewritten.

The original local history remains the development record; the private publication commit records the delivered source. Release assets are individually hashed before upload and retrieved for SHA-256 verification. The final manifest records actual remote visibility, commit, tag, sizes and verification results. Repository creation alone is not a release or public deployment.

CLA acceptance remains separate: approved startup context was present, and real awareness tools returned the approved immutable snapshot. This demonstrates context/tool access. It does not independently attest the launcher process tree or prove poker correctness. Old evidence is not renewed by a new report. Raw launch data is retained only in its original private location.
